# 🚀 My Interest Towards Cloud Computing

Since my 10th standard, I have always been curious about how large-scale platforms like Google products work so smoothly for millions of users simultaneously without conflicts or interruptions.

I used to wonder:

- How multiple users can edit and access applications at the same time
- How systems remain available 24/7
- How applications scale globally for millions of users
- How data synchronization works without collisions

At that time, I did not know the actual technology behind these systems.

Later, I discovered that many modern applications and scalable systems are powered by the principles of Cloud Computing.

That curiosity gradually developed into a strong interest in cloud technologies, deployment workflows, infrastructure management, scalability, and DevOps practices.

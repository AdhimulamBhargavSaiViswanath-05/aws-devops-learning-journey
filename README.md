# 🚀 My Interest Towards Cloud Computing

Since my 10th standard, I have always been curious about how large-scale platforms like Google products work seamlessly for millions of users simultaneously without interruptions or conflicts.

I used to wonder:

- How multiple users can access and edit applications at the same time
- How systems remain available continuously
- How applications scale globally
- How data synchronization works efficiently

At that time, I did not know the technology behind these systems.

Later, I discovered that many modern scalable applications operate using the principles of Cloud Computing.

That curiosity gradually developed into a strong interest in cloud technologies, infrastructure management, deployment workflows, scalability, and DevOps practices.

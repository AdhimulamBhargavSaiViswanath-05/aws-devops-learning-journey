# ⚙️ Windows Server Setup Steps using AWS EC2

## Step 1 — Open EC2 Dashboard

- Login to AWS Console
- Navigate to EC2 Service
- Click Launch Instance

---

# Step 2 — Configure Instance

- Enter server name
- Select Windows Server AMI
- Create a new PEM key pair
- Configure storage and network settings
- Enable HTTP and HTTPS traffic

---

# Step 3 — Launch Instance

- Click Launch Instance
- Wait for instance to enter Running state

---

# Step 4 — Connect to Instance

- Open instance details
- Click Connect
- Select RDP Client option

---

# Step 5 — Download RDP File

- Download Remote Desktop file
- Save locally

---

# Step 6 — Generate Password

- Click Get Password
- Upload PEM key file
- Click Decrypt Password

---

# Step 7 — Connect using RDP

- Open downloaded RDP file
- Enter generated password
- Accept permissions
- Successfully connect to remote Windows server

---

🚀 Windows Server Setup Completed Successfully

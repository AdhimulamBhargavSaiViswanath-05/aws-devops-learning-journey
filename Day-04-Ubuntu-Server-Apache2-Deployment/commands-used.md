# 💻 Commands Used – Day 4

## 👑 Switch to Root User

```bash
sudo su -
```

---

# 📦 Update Ubuntu Packages

```bash
apt-get update -y
```

---

# 🌐 Install Apache2

```bash
apt-get install apache2 -y
```

---

# ▶️ Start Apache2 Service

```bash
service apache2 start
```

---

# 📂 Navigate to Apache Web Directory

```bash
cd /var/www/html
```

---

# ✏️ Create/Edit File using Nano

```bash
nano filename.html
```

---

# 💾 Nano Shortcuts

## Save File

```text
Ctrl + O
```

## Confirm Save

```text
Enter
```

## Exit Nano Editor

```text
Ctrl + X
```

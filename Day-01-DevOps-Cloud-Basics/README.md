# ☁️ Day 1 – DevOps & Cloud Computing Fundamentals

## 📌 Objective

The objective of Day 1 was to understand the fundamental concepts of DevOps, Cloud Computing, AWS basics, and modern software development workflows.

---

# 🚀 Introduction to DevOps

DevOps is a modern software development approach that improves collaboration between:

- Development Team
- Operations Team

The primary goal of DevOps is to automate processes, improve deployment speed, increase reliability, and enable continuous delivery of applications.

---

# 🔄 SDLC Methodologies

## Waterfall Model

A traditional linear software development model where each phase is completed before moving to the next phase.

### Limitations
- Difficult to make changes
- High risk during late testing
- Slow delivery process

---

## Agile Model

An iterative software development methodology focused on:

- Continuous improvement
- Customer feedback
- Faster releases
- Team collaboration

Agile enables flexible and faster software development.

---

# ☁️ Introduction to Cloud Computing

Cloud Computing refers to accessing computing resources such as:

- Servers
- Storage
- Databases
- Networking
- Applications

through the internet from anywhere at any time.

---

# 🏗️ Cloud Service Models

## IaaS – Infrastructure as a Service

Provides infrastructure resources such as:
- Virtual Machines
- Storage
- Networking

Example:
AWS EC2

---

## PaaS – Platform as a Service

Provides a platform for developers to:
- Build
- Test
- Deploy applications

without managing infrastructure.

---

## SaaS – Software as a Service

Provides ready-to-use software applications through the internet.

Examples:
- Gmail
- Google Drive
- Facebook

---

# 🌍 Cloud Deployment Models

## Public Cloud
Services available publicly over the internet.

## Private Cloud
Cloud infrastructure dedicated to a single organization.

## Hybrid Cloud
Combination of both Public and Private Cloud.

---

# 🟧 Introduction to AWS

Amazon Web Services (AWS) is a leading cloud computing platform launched by Amazon in 2006.

AWS provides:
- Compute Services
- Storage
- Networking
- Databases
- Security
- Deployment Services

on a pay-as-you-use model.

---

# 🌐 AWS Global Infrastructure

AWS infrastructure consists of:

## Regions
Physical geographic locations containing AWS data centers.

## Availability Zones (AZs)
Multiple isolated data centers inside a region for high availability.

## Edge Locations
Used for low-latency content delivery and faster access.

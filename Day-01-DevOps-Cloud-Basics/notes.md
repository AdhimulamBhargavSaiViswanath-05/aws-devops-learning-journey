# 📝 Day 1 Quick Notes – DevOps & Cloud Computing

## 🚀 DevOps

### Definition
DevOps is a software development approach that improves collaboration between:
- Development Team
- Operations Team

### Main Goals
- Faster deployment
- Automation
- Continuous Integration
- Continuous Delivery
- Improved reliability

---

# 🔄 SDLC Models

## Waterfall Model
- Traditional model
- Linear process
- One phase after another
- Difficult to modify later

### Disadvantages
- High risk
- Slow delivery
- Difficult testing changes

---

## Agile Model
- Iterative development
- Faster releases
- Flexible changes
- Customer collaboration

### Advantages
- Continuous feedback
- Better adaptability
- Faster development cycle

---

# ☁️ Cloud Computing

### Definition
Cloud Computing means accessing:
- Servers
- Storage
- Databases
- Networking
- Applications

through the internet from anywhere.

---

# 🏗️ Cloud Service Models

## IaaS
Infrastructure as a Service

Provides:
- Virtual machines
- Storage
- Networking

Example:
AWS EC2

---

## PaaS
Platform as a Service

Provides:
- Development platform
- Deployment environment

Used by developers.

---

## SaaS
Software as a Service

Ready-to-use software over the internet.

Examples:
- Gmail
- Facebook
- Google Drive

---

# 🌍 Cloud Deployment Models

## Public Cloud
Available for everyone.

## Private Cloud
Used by a single organization.

## Hybrid Cloud
Combination of Public + Private cloud.

---

# 🟧 AWS Basics

### AWS
Amazon Web Services

### Launched
2006

### Features
- Pay-as-you-use
- Scalable
- Global infrastructure
- High availability

---

# 🌐 AWS Global Infrastructure

## Regions
Geographical AWS locations.

## Availability Zones
Multiple isolated data centers inside regions.

## Edge Locations
Used for faster content delivery and reduced latency.

---

# 🧠 Important Learning Points

- DevOps improves collaboration
- Agile is more flexible than Waterfall
- Cloud Computing enables remote infrastructure access
- AWS is a leading cloud platform
- Regions and AZs improve availability and reliability
